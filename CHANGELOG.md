## Unreleased

- Удалённые desktop-модели могут работать с открытым проектом напрямую, без OpenHands Agent Server, после отдельного разрешения пользователя для этой папки.
- Добавлены инструменты списка файлов, чтения, поиска, записи и запуска команд; запись и команды терминала ждут подтверждения, изменения можно отменить.
- Ограничены пути проекта, размер контекста и вывода, глубина поиска и время выполнения команд. Android остаётся в режиме удалённого чата без доступа к desktop-файлам.
- Исправлена оценка RAM: полный GPU offload также оставляет GGUF в рабочем наборе Windows-процесса; предохранитель резервирует весь файл и запас runtime/контекста. Добавлены проверки оценок для Nemotron 8B и Ternary Bonsai 27B.
- Ответы провайдера с HTTP 200 и вложенным объектом `error` теперь показывают исходную причину и код, вместо общего сообщения о пустом ответе.
- При rate limit Kilo причина читается из nested `previous_errors`; внутренний gateway user ID не попадает в сообщение приложения.
- При временном HTTP 429 Kilo приложение с паузой пробует до трёх других бесплатных моделей; для агентских задач резервные модели должны поддерживать вызов инструментов. При общем ограничении выдаётся понятная инструкция повторить позже.
- Проверен локальный HIP runtime на Radeon RX 7700 XT с Nemotron 8B Q6 и контекстом 16K: OpenHands 1.26.0 получил ответ локальной модели, запросил подтверждение для `file_editor`, затем создал файл в изолированном workspace. Короткая генерация — около 54 токенов/с; после агентского прохода оставалось около 1,0 ГиБ свободной RAM. Это интеграционный тест, не длительный тест стабильности. Ternary Bonsai 27B не запускалась: её GPU-оценка требует около 8,0 ГиБ свободной RAM, CPU-оценка — около 11,5 ГиБ.
- Не включено в опубликованный релиз v1.0.16-beta.2. Сквозной backend-цикл с mock OpenAI-compatible сервером и approval прошёл; Kilo Gateway в live-запросе вернул tool_calls. Проверка полного Tauri UI сценария с живым провайдером ещё нужна.

## v1.0.17-beta.3 — кандидат к публикации

- Добавлен автоматический переход на резервную бесплатную модель Kilo при HTTP 429 с фильтрацией моделей без tool calling для агентских задач.
- Полностью проверен локальный агентский цикл Windows: HIP + Nemotron 8B Q6, OpenHands Agent Server 1.26.0, tool call `file_editor`, подтверждение и запись файла в тестовый workspace.
- RAM-предохранитель учитывает рабочий набор GGUF в системной памяти и резерв контекста даже при GPU offload.
- Локальный llama.cpp запускается с одним серверным слотом, поскольку приложение выполняет одну агентскую задачу за раз; это избегает лишнего резерва KV-кэша.
- CI релиза запускает Rust fmt, strict Clippy и тесты перед сборкой Windows и Android пакетов.
- Beta с ограничениями: длительная стабильность модели, UI-сценарий удалённого агента и установка APK на Android-устройство не проверены.
