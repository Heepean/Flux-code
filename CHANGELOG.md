# История изменений

## v1.0.7

- Установщик содержит исправления проверки готовности локальной модели: приложение подтверждает ответ текущего процесса llama-server.
- При неудачном старте локальной модели приложение останавливает оставшийся процесс и снимает состояние активности.
- Загрузчик llama.cpp проверяет SHA-256 официального Windows CPU-архива перед установкой.
- Запуск GGUF блокируется с понятным сообщением, если свободной RAM недостаточно.

## v1.0.6

- Добавлен динамический каталог бесплатных текстовых моделей Kilo Gateway с выбором в настройках агента.
- Kilo Free работает без аккаунта и API-ключа; отображаются поддержка tool calling и контекст модели.
- Каталог отбирает бесплатные текстовые модели по данным официального API Kilo.
- Интеграция использует REST API разговоров OpenHands 1.26.0, продолжает историю при смене модели и показывает только новые события и вывод инструментов.
- Автообновление откладывает перезапуск, пока агент выполняет задачу или загружается локальная модель.

## v1.0.5

- Поток агента сохраняет UTF-8 текст, даже если символ разделён между сетевыми пакетами.
- В ленте задач отображаются вызовы инструментов OpenHands; успешный запуск инструментов без текстового ответа больше не помечается как ошибка.

## v1.0.4

- Локальная GGUF-модель автоматически подготавливает официальный llama.cpp CPU runtime, если `llama-server.exe` не указан.
- Контекст по умолчанию уменьшен до 4096 токенов; добавлены настройки контекста и GPU-слоёв.
- Ошибки чтения/сохранения проекта отображаются в статусе, Hugging Face GGUF загружаются в папку выбранного проекта без перезаписи существующих файлов.

## v1.0.3

- Включена генерация подписанных updater-артефактов для Windows-сборок.
- Исправлена публикация подписанного манифеста для автоматической проверки обновлений.

## v1.0.2

- Исправлена подготовка подписанного установщика и манифеста автообновления для GitHub Releases.

## v1.0.1

- Подключение удалённых OpenAI-compatible моделей через OpenHands Agent Server.
- Хранение API-ключа в системном Windows Credential Manager, проверка HTTPS endpoint-ов и loopback-only HTTP.
- Сохранение ID беседы, чтобы продолжать проектную сессию после смены модели.
- Показывать версию приложения 1.0.1 в строке состояния.

## v1.0.0

- Первый релиз отдельного приложения Flux Hands на Tauri.
- Редактор Monaco, файловое дерево и локальная работа с проектом.
- Управление GGUF-моделями и Hugging Face.
- Встроенный запуск OpenHands Agent Server 1.26.0, локальный профиль модели и потоковый чат агента.
- Подписанные обновления при запуске и каждые 24 часа.
