# Flux Hands

**Локальные модели и AI-инструменты для разработки — в одном рабочем пространстве.**

Flux Hands объединяет редактор проекта, проводник, поиск, Git-инструменты и AI-чат. На Windows можно работать с локальными GGUF-моделями и запускать OpenHands Agent Server для задач с доступом к проекту. Удалённые модели подключаются напрямую: для обычного чата Agent Server не нужен. Android-приложение предназначено для удалённого чата и не запускает локальные модели или Agent Server.

> **Релизы, установщики и APK:** [страница Flux Hands Releases](https://github.com/Heepean/Flux-code/releases). Windows updater получает подписанный manifest после публикации полностью проверенного релиза.

## Текущие изменения исходников

На Windows удалённая модель может использовать инструменты открытого проекта без Agent Server, если включить разрешение для этой папки. Содержимое файлов передаётся выбранному провайдеру; чтение и поиск выполняются внутри проекта, а запись файлов и команды терминала требуют отдельного подтверждения. Android остаётся удалённым чатом без доступа к desktop-проектам. Kilo Gateway уже вернул tool call в безопасном live-запросе, а backend-цикл с подтверждением проверен на локальном mock сервере. Перед релизом ещё нужна проверка полного сценария из Tauri UI с живым провайдером.

Для Kilo добавлен автоматический fallback при upstream HTTP 429: после ограниченной паузы Flux Hands пробует до трёх других бесплатных моделей, а для agent-задач — только модели с tool calling. Если доступные варианты тоже ограничены, приложение показывает короткую инструкцию повторить запрос позже и не раскрывает внутренний gateway user ID.

В Kilo-каталоге показываются модели, которые сам шлюз в данный момент отмечает бесплатными; названия и наличие обновляются динамически. Включаемая оркестрация выполняет три последовательных запроса: планировщик, выбранная модель-исполнитель и модель-проверяющий. Каждый запрос расходует отдельный лимит провайдера. На текущем снимке каталога бесплатных DeepSeek и Qwen нет; их платные/ключевые API можно задать в разделе совместимого удалённого провайдера.

На Windows добавлена медиатека проекта: импорт изображений, аудио и видео в `media/`, предпросмотр и сохранение копий через системный диалог. Растровые изображения можно повернуть на 90° или перевести в чёрно-белый режим с сохранением отдельного PNG; видео можно обрезать по временным границам и сохранить как WebM. SVG можно создавать и редактировать через агента с подтверждением записи. Предпросмотр очень больших файлов ограничен по размеру. Эти функции медиатеки пока предназначены для desktop; на Android остаётся прямой удалённый чат.

Локальная связка проверена на Windows с `nvidia_Nemotron-Cascade-8B-Q6_K.gguf`: OpenHands Agent Server 1.26.0 запустился рядом с llama.cpp HIP на Radeon RX 7700 XT (HIP сообщил 12 272 МиБ VRAM). Проверен режим с одним llama.cpp slot: модель ответила, вызвала `file_editor`, дождалась подтверждения и создала файл в отдельном временном workspace; разговор завершился со статусом `finished`. Короткая генерация дала около 47–54 токенов/с; свободная системная RAM после полного агентского прохода снижалась примерно до 1,0 ГиБ. Это подтверждает функциональную интеграцию, но не длительную устойчивую работу. RAM-предохранитель учитывает, что GGUF остаётся в рабочем наборе процесса даже при полной выгрузке слоёв на GPU. Для Ternary Bonsai 27B оценка составляет около 8,0 ГиБ свободной RAM при полном GPU offload и 11,5 ГиБ в CPU режиме; на этом снимке было около 7,7 ГиБ, поэтому её запуск блокируется до освобождения памяти.

## Возможности

### Windows

- Открывайте существующую папку проекта или создавайте для проекта новую.
- Просматривайте файлы, редактируйте их в Monaco, сохраняйте изменения и ищите по проекту.
- Проверяйте состояние Git и смотрите diff изменений.
- Подключайте удалённые OpenAI-compatible API напрямую для обычного чата.
- Выбирайте локальную GGUF-модель. Flux Hands запускает её через `llama.cpp`; доступное ускорение зависит от оборудования и установленного runtime.
- Для работы локального агента приложение запускает OpenHands Agent Server. Действия с файлами и командами показываются для подтверждения.
- Ищите GGUF-модели на Hugging Face и загружайте выбранные файлы в приложение.

### Android 15+

- Общайтесь с Kilo Free без аккаунта или подключайте совместимый удалённый API.
- Android использует прямой чат с выбранным провайдером. Agent Server, локальные модели и доступ к файлам проекта на телефоне не запускаются.
- API-ключ стороннего провайдера действует только до закрытия приложения и после перезапуска вводится заново.

## Первый запуск локальной модели на Windows

1. Откройте или создайте папку проекта.
2. В разделе **Модели** выберите `.gguf` с диска или найдите модель на Hugging Face.
3. Настройте и запустите локальный runtime. Скорость зависит от размера модели, контекста, доступной RAM и GPU.
4. Для агентской задачи выберите локальную модель, перейдите в **Agent workspace** и отправьте запрос. Агент изучит проект и запросит подтверждение перед выполнением поддерживаемых действий.

Без разрешения на доступ к проекту удалённой модели отправляются только сообщения чата. Если включить доступ для конкретной папки, файлы могут передаваться провайдеру; запись и терминальные команды показываются для подтверждения.

## Провайдеры и приватность

Бесплатные модели Kilo доступны без аккаунта Flux Hands и API-ключа, но действуют ограничения самого провайдера, а каталог моделей может меняться. Платные и сторонние API используют правила, цены и лимиты соответствующего сервиса. Не отправляйте удалённому провайдеру конфиденциальный код, если его условия хранения вам не подходят.

Локальные модели выполняют inference на вашем ПК. Загрузка модели, llama.cpp и компонентов Agent Server требует интернета. Результаты модели могут содержать ошибки: проверяйте предложенные изменения и diff перед принятием.

## Статус проверки

Windows updater получает подписанный manifest из GitHub после подтверждённой публикации полного релиза. Workflow обновляет и raw manifest для новых сборок, и `latest.json` стабильного GitHub Release для уже установленных старых версий. Проверка выполняется не чаще раза в 24 часа, дата сохраняется между перезапусками, пакет устанавливается после проверки подписи. APK собирается GitHub Actions; для локальной APK-сборки нужен Android NDK.

Пока **не подтверждены** установка Windows-сборки на чистой системе, обновление установленной версии и запуск APK на физическом Android-устройстве. Этот релиз предназначен для тестирования; сообщайте об ошибках через [Issues](https://github.com/Heepean/Flux-code/issues).

## Сборка из исходников

Нужны Node.js, Rust toolchain и WebView2 Runtime.

```powershell
npm ci
npm run build
npm run tauri -- dev
```

Создать Windows установщики NSIS и MSI:

```powershell
npm run build:desktop
```

Артефакты создаются в `src-tauri/target/release/bundle/`.
