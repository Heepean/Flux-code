# Flux Hands

Ваша среда разработки. Ваши модели. Ваш контроль.

Flux Hands — Windows-приложение, которое объединяет редактор проекта, локальные языковые модели и автономного агента OpenHands. Вы открываете папку проекта, выбираете GGUF-модель и поручаете агенту изучать и изменять проект из одного рабочего пространства.

![Flux Hands: редактор проекта и рабочее пространство агента](docs/images/flux-hands-workspace.png)

## Что уже работает

- Тёмная оболочка приложения с редактором Monaco, проводником и вкладкой агента.
- Открытие папки проекта, просмотр файлов и сохранение изменений.
- Запуск локальной GGUF-модели через `llama-server`; при переключении модели предыдущий процесс останавливается.
- Автоматическая загрузка официального llama.cpp CPU runtime при первом запуске локальной модели, если сервер не указан вручную.
- Поиск моделей GGUF на Hugging Face, просмотр файлов и загрузка выбранной модели.
- Локальный OpenHands Agent Server 1.26.0 с потоковым ответом в интерфейсе.
- Передача выбранной модели llama.cpp в профиль OpenHands и привязка агента к текущему проекту.
- Подключение удалённых OpenAI-compatible endpoint-ов; API-ключ хранится в Windows Credential Manager.
- Переключение модели OpenHands сохраняет текущую историю беседы и продолжает работу в том же проекте.
- Актуальный каталог бесплатных текстовых моделей Kilo Gateway и подключение без аккаунта/API-ключа; для каждой модели показывается заявленная поддержка tool calling.
- Создание локального ключа Agent Server без учётной записи Flux Hands.

Первый запуск Agent Server скачивает официальный `uv`/`uvx` и нужные Python-пакеты. Первый запуск локальной модели при необходимости загружает CPU-сборку llama.cpp из официального GitHub release. Для этих шагов требуется интернет. Модель остаётся локальной; скорость зависит от модели, доступной RAM и оборудования. CPU-сборка работает без GPU, но медленнее; GPU-сборку llama.cpp пока нужно указать вручную.

## Скачать для Windows

Последние установщики доступны на странице [релизов Flux Hands](https://github.com/Heepean/Flux-code/releases/latest): выберите NSIS (`*-setup.exe`) или MSI.

## Начало работы

1. Установите Flux Hands и откройте папку проекта.
2. Во вкладке **Модели** выберите существующий `.gguf` или найдите модель на Hugging Face.
3. Выберите GGUF и нажмите **Запустить**. Если `llama-server.exe` не найден, приложение скачает официальный CPU runtime llama.cpp и подготовит его автоматически. По умолчанию используется контекст 4096 токенов, его можно изменить в настройках модели.
4. Для бесплатной удалённой модели откройте настройки моделей, выберите **Kilo · бесплатные модели**, обновите каталог и выберите модель. Для локального режима запустите GGUF. Затем перейдите в **Agent workspace** и опишите задачу. При первом запуске OpenHands runtime приложение загрузит необходимые Python-компоненты.

Закрытые модели и файлы Hugging Face могут требовать личный токен. Для удалённых моделей укажите адрес API и ключ провайдера; цены и лимиты устанавливает сам провайдер. Бесплатные модели Kilo доступны без аккаунта и ключа, но Kilo ограничивает анонимный доступ до 200 запросов в час на IP; состав каталога меняется. Некоторые upstream-провайдеры могут сохранять запросы, поэтому не передавайте конфиденциальный код. Поддержка tool calling зависит от выбранной модели. Локальные модели не требуют учётной записи или ключа. Файлы runtime загружаются в каталог данных Flux Hands, GGUF из Hugging Face — в папку текущего проекта.

## Сборка из исходников

Требуются Node.js, Rust toolchain и WebView2 Runtime.

```powershell
npm ci
npm run build
npm run tauri -- dev
```

Создать установщики NSIS и MSI:

```powershell
npm run build:desktop
```

Артефакты появятся в `src-tauri/target/release/bundle/`.
