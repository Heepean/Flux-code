# Flux Hands

**Локальные модели и AI-инструменты для разработки — в одном рабочем пространстве.**

Flux Hands объединяет редактор проекта, проводник, поиск, Git-инструменты и AI-чат. На Windows можно работать с локальными GGUF-моделями и запускать OpenHands Agent Server для задач с доступом к проекту. Удалённые модели подключаются напрямую: для обычного чата Agent Server не нужен. Android-приложение предназначено для удалённого чата и не запускает локальные модели или Agent Server.

## Возможности

### Windows

- Открывайте существующую папку проекта или создавайте для проекта новую.
- Просматривайте файлы, редактируйте их в Monaco, сохраняйте изменения и ищите по проекту.
- Проверяйте состояние Git и смотрите diff изменений.
- Подключайте удалённые OpenAI-compatible API напрямую для обычного чата.
- Выбирайте локальную GGUF-модель. Flux Hands запускает её через `llama.cpp`; доступное ускорение зависит от оборудования и установленного runtime.
- Для работы локального агента приложение запускает OpenHands Agent Server. Действия с файлами и командами показываются для подтверждения.
- Ищите GGUF-модели на Hugging Face и загружайте выбранные файлы в приложение.

### Android 15+

- Общайтесь с Kilo Free без аккаунта или подключайте совместимый удалённый API.
- Android использует прямой чат с выбранным провайдером. Agent Server, локальные модели и доступ к файлам проекта на телефоне не запускаются.
- API-ключ стороннего провайдера действует только до закрытия приложения и после перезапуска вводится заново.

## Первый запуск локальной модели на Windows

1. Откройте или создайте папку проекта.
2. В разделе **Модели** выберите `.gguf` с диска или найдите модель на Hugging Face.
3. Настройте и запустите локальный runtime. Скорость зависит от размера модели, контекста, доступной RAM и GPU.
4. Для агентской задачи выберите локальную модель, перейдите в **Agent workspace** и отправьте запрос. Агент изучит проект и запросит подтверждение перед выполнением поддерживаемых действий.

Удалённый чат работает иначе: выбранный текст и контекст переписки отправляются провайдеру, а локальные файлы проекта и инструменты агента в таком режиме недоступны.

## Провайдеры и приватность

Бесплатные модели Kilo доступны без аккаунта Flux Hands и API-ключа, но действуют ограничения самого провайдера, а каталог моделей может меняться. Платные и сторонние API используют правила, цены и лимиты соответствующего сервиса. Не отправляйте удалённому провайдеру конфиденциальный код, если его условия хранения вам не подходят.

Локальные модели выполняют inference на вашем ПК. Загрузка модели, llama.cpp и компонентов Agent Server требует интернета. Результаты модели могут содержать ошибки: проверяйте предложенные изменения и diff перед принятием.

## Сборка из исходников

Нужны Node.js, Rust toolchain и WebView2 Runtime.

```powershell
npm ci
npm run build
npm run tauri -- dev
```

Создать Windows установщики NSIS и MSI:

```powershell
npm run build:desktop
```

Артефакты создаются в `src-tauri/target/release/bundle/`.
