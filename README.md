# Flux Code

Flux Code — локальная AI-среда разработки для Windows: редактор кода, терминал, Git и агент в интерфейсе, вдохновлённом Codex.

## Быстрый старт

1. Скачайте и установите последний `Flux-Code-setup.exe` из [Releases](https://github.com/Heepean/flux-code/releases/latest).
2. Откройте **Настройки**, установите llama.cpp, выберите GGUF-модель и запустите её — или подключите Ollama/OpenAI-совместимый API.
3. Откройте папку проекта, редактируйте файлы в рабочем месте или поручите задачу агенту в чате.
4. Разрешение агента на доступ к файлам и командам задаётся переключателем в чате. Автообновления включаются отдельно в **Настройки → Обновления Flux Code**.

## Обновления

В настройках включите **Автоматически устанавливать обновления**. Приложение проверяет подписанные релизы GitHub при запуске и каждые 12 часов, устанавливает их и перезапускается. Переключатель выключен по умолчанию. Без него обновление можно проверить вручную.

## Для разработчиков

Требуются Node.js, Rust toolchain и WebView2 Runtime.

```powershell
npm install
npm run tauri dev
```

Сборка Windows установщика: `npm run tauri build`.

Локальные модели не имеют квот Flux Code, но зависят от ресурсов компьютера и контекста модели. У облачных API свои тарифы и лимиты. Для LSP/DAP нужен установленный сервер/адаптер; расширения VS Code пока не поддерживаются.
